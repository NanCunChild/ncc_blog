## Yubikey5C 功能概述
Yubikey功能非常多！但是一定一定注意不要买错，特别是二手市场淘金时。

### 目前产品分类
- **Security Key Series（第二代为蓝色基础款，第一代也是黑色）**
    
    - **功能**：**纯粹的 FIDO/U2F 和 FIDO2/WebAuthn 认证器**。没有 OpenPGP，没有 TOTP（不能存动态密码），没有 PIV 智能卡。
        
    - **适合人群**：**普通大众用户、小白用户**。只需要给 Google、GitHub绑定一个防钓鱼的硬件，或者只用 FIDO2 登录 SSH，追求极简和高性价比。
        
- **YubiKey 5 Series（黑色全功能款，NCC的这款）**
    
    - **功能**：**全能！瑞士军刀！**。囊括了 FIDO、OpenPGP、PIV、OATH、YubiOTP 等所有协议。
        
    - **适合人群**：**开发者、系统管理员、极客、加密爱好者以及NCC**。对于需要管理 GPG 密钥、各种服务器、多套数字身份的硬核玩家，5 系列是最佳选择。
        
- **YubiKey 5 FIPS Series（黑色合规款）**
    
    - **功能**：功能与 5 系列完全一致，但硬件和固件通过了 **FIPS 140-2 / 140-3** 认证。由于需要满足严格合规，它的固件被彻底锁死，且在某些密码学操作上限制了自定义能力。
        
    - **适合人群**：**政府雇员、国防承包商、金融/医疗机构员工**。个人玩家完全不需要买（买了反而因为限制多而觉得不好用），这是专门为了过安全审计生产的。
        
- **YubiKey Bio Series（指纹生物识别款）**
    
    - **功能**：带指纹识别。支持 FIDO 和部分 PIV 功能，但**不支持 OpenPGP 和 TOTP**。
        
    - **适合人群**：**企业办公人群**。主要用于无密码登录（比如 Windows Hello 或企业级单点登录）。企业希望员工连 PIN 码都不用记，直接按指纹就能解锁。对于需要 GPG 签名的玩家来说，Bio 系列反而功能不够用。
        
- **YubiHSM 2 & YubiHSM 2 FIPS（硬件安全模块）**
    
    - **功能**：这是一个微型的服务器端硬件加密机，主要用于保护服务器的证书颁发机构 (CA)、数据库加密密钥等，不在终端用户的设备上插拔。官网给的图片就是插进服务器内部的USB口中，扩展加密功能，永远不拿出来。
        
    - **适合人群**：**企业后端运维、企业级服务器管理员**。个人用户不接触。
        
-  **Accessories（配件，官网居然还把这个单独卖）**
    
    - 就是防丢绳、保护套之类的周边。

### 关于老版本密钥的补充
在淘旧货时可能会遇到这两个东西来以次充好：`Security Key Series` 和 `Yubico 4 Series` 
并不一味的建议就要买“正品”，而是把这些缺点和优势贴出来给大家来选择：

- Yubikey 4
	- **情况**：这是上一代产品了，2018年左右停产，而且官方进行了批量召回，目前二手市场会卖得很便宜，而且无良卖家会刻意不说具体型号，只以“高级安全密钥”、“Yubico高级系列”做卖点。来源：[Yubico Support for YubiKey4](https://support.yubico.com/s/article/YubiKey-4)
		- 硬件漏洞：CVE-2017-15361（ROCA漏洞），Infineon 提供的RSA加密套件库有问题，能只通过RSA公钥计算出私钥。这个可太严重了，是Yubico召回的直接原因。
			
		- 算法过时：根据官网留存的技术资料描述，其实支持的功能不算少，PIV、OpenPGP、U2F、OTP等全部支持，但是密码学算法只支持RSA系列，最高 RSA-4096。这个在目前本身不是问题，但是有些激进的平台为了安全性只支持 `ed225519-sk` 算法，以及未来新算法的全面普及下，这个密钥就无法适配。
- Security Key
	- **情况**：本身没问题，也是Yubico的正经产品之一，但是这个产品线也是经历了一轮更新。第一代是蓝色的，中央是一个钥匙图案；第二代为了统一产品形象都变成了黑色，而且中央也变成了“Y”字样，外观和YubiKey系列难以区分，但是去看反面靠接口的地方可以看到：YubiKey系列有一个二维码，带8位数字ID；Security Key系列只有一个FIDO字样。
		- 功能限制：只有FIDO2登录，而且第一代蓝色的没有 `ed25519-sk` 算法，性价比很低，即使要也买一个第二代的黑色版本。
		- 优点：便宜，官网29刀一个，还可以去别的地方捡20%优惠券。

### 关于YubiKey5早期漏洞的传言
YubiKey5早期有漏洞，固件版本低于5.7的版本存在 `CVE-2024-45678` ，侧信道漏洞能提取出私钥（加密算法有问题，又是Infineon的锅），这让很多玩家都不敢购买二手Key。
但是这个漏洞利用门槛非常高，需要电磁探针和纳米级分辨率示波器，还需要相关专家调试才有可能利用。
总的来说，利用者需要满足：
1. 偷走物理钥匙；
2. 知道账号密码或 PIN 码；
3. 拥有实验室微波和电磁探测设备；
4. 在挂失前完成复杂的破解。
这属于APT攻击级别了，大多极客玩家的秘密都没这些仪器和专家工资的万分之一贵。而且退一万步来说，就算没有时序攻击漏洞，也是可以拆开拿电子显微镜和蚀刻分析拿私钥的，所以个人玩家可以不用太担心这个问题。如果仍然是希望完美密钥，那就需要记得在购买前协商好版本。 `ykman` 指令，Yubico Authentication App 等都可以看到固件版本，只要在5.7之后即为安全。
截至2026年4月16日，目前咸鱼上有漏洞的版本价格多在200人民币左右，5.7.1版本多在400左右，最新官网价格为69美元，中国正经代理商贴出价格为699人民币。

同时，Yubico公司有时会做联动活动，NCC看到有人在 Yubico&Cloudflare时期20美刀一个买了十几个，真的酸哇。

### 恢复身份的长征

#### OpenPGP 的恢复

首先，找到主密钥！NCC在之前离线备份过密钥，进行了二维码和打印备份，在github提交，去中心化聊天中将用它证明身份。

最佳实践是离线环境导入主密钥，然后进行如下全部操作。

```bash
gpg --list-key  # 列出本地所有GPG密钥
```

输出格式如下，pub后跟着的是主密钥，每个sub后跟着的是子密钥。为了对这一串密钥进行操作，需要定位pub后面的ID进行edit模式。

```text
pub   ed25519 2026-03-18 [C]  
     XXXXXXXXXXXX3F1897DA95D89C2A58BAC2CFD595  
uid             [ 绝对 ] NanCunChild (NCC's Master GPG Key, Certify Only) <nancunchild@gmail.com>  
sub   ed25519 2026-04-22 [S] [有效至：2031-04-21]  
sub   cv25519 2026-04-22 [E] [有效至：2031-04-21]  
sub   ed25519 2026-04-22 [A] [有效至：2031-04-21]
```

```bash
gpg --edit-key XXXXXXXXXXXX3F1897DA95D89C2A58BAC2CFD595  # 填入你的密钥ID
```

进入edit模式之后，命令行会变成 `gpg>` ，表明进入了gpg命令模式，可以输入 `help` 获取指令帮助。

NCC过去为了测试创建和吊销了多个子密钥，所以这里都会留存，这一长串同时表明目前有效的密钥内容和已经失效的密钥。

使用 `key X` 指令可以选中密钥，X为顺数第几个密钥。选中的密钥前会标识 `*` 号。对丢失的密钥指定 `revkey` 进行撤销，等这个撤销公布时，旧的将在共识网中作废。完成全部操作后

> 注意！key指令为复选，当完成操作之后这个密钥仍然处于选中状态，再次输入 `key X` 以取消。防止误操作。

撤销了相关丢失密钥后，使用 `addkey` 指令可以新生成子密钥，标准密码流程是签名、加密和认证三者分开。在使用 `addkey` 指令后将会出现密钥用途选择。部分gpg版本不支持直接添加认证密钥，必须要认证密钥和签名密钥结合，此时可以进入专家模式，`gpg --expert --full-generate-key` 即可自由选择非默认算法组合以及自定义密钥用途。

生成之后在交互界面使用 `keytocard` 即可选定将指定子密钥导入到yubikey中，使用save将固化操作。注意，此导入操作将删除本地对应子密钥而且无法撤销。
